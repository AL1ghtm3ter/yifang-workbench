# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Individuals who use several independent local or hosted web projects, and developers who customize a personal workspace with their own coding agents.

## Product Purpose

Keep entry points, reading preferences and personal notes together without taking ownership of the connected projects.

## Operating Context

A local-only Node server and a browser. Each connected project runs its own service. Coding agents edit this repository under human direction; the shell does not call models.

## Capabilities and Constraints

Configuration registry, iframe workspaces, themes, search, recent projects, private browser notes and backups. No bundled user projects, accounts, credentials, reverse proxies or automatic project startup. External sites may block framing.

## Brand Commitments

Yifang Workbench. Default is a readable personal desk inspired by Song aesthetics: rice-paper ground, ink text, restrained vermilion; body uses a clear sans-serif and headings use serif.

## Product Principles

Independent source ownership. Explicit integration. Personal records stay personal. Accessibility and clarity before decoration. Customization stays editable and testable.
