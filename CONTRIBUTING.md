# Contributing

Use Node.js22+. Run npm test, npm run build and npm run check:public. Explain behavior changes and the actual browser paths checked in your PR.

New themes belong in src/themes and must cover every semantic token, light/dark, readable text and reduced motion. New adapters must preserve independent project ownership and explicit message origins.

Never attach real project screenshots, personal backups, credentials, databases or local configs to public issues. Use synthetic reproductions.

The code is MIT licensed. Do not add assets or copied code without compatible redistribution rights and attribution.
