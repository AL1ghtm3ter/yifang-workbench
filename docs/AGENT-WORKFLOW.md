# 开发者与自己的Agent

本项目提供代码和约定，不绑定Agent产品或模型。

1. 把仓库放在自己的编码Agent可访问的位置。
2. 让它读AGENTS.md、PRODUCT.md和DESIGN.md，告诉它你的风格、使用场景与项目地址。
3. 风格修改放主题文件；真实项目配置放被忽略的config.local.json。
4. 要求它先展示可点击的局部方案，保留项目边界和已有功能。
5. 修改后跑测试、构建、公开文件检查，并用浏览器验证。
6. 发布自己的分支前，检查实际提交文件和项目地址。

界面“给Agent的说明”只是可复制提示，不会发消息、启动Agent、读取会话或购买额度。可以选择自行安装Impeccable帮助设计，但它不是必需依赖，也未捆绑在本项目中。

## 验收建议

用真实独立测试服务检查：进入、返回、并排切换、保留页面输入、重载、主题消息来源校验；坏配置/坏备份不覆盖记录；另一标签更新时暂停覆盖；备份预览后发生变化时拒绝恢复。截图和测试结果属于证据，不能单凭一个HTTP200宣布项目接入成功。
