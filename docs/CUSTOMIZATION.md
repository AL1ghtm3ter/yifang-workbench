# v0.2 定制工作流

## 接入向导

首页“接入项目”填写唯一ID、名称、URL、图标、分组和标签，可先打开原页试载。生成的配置会校验地址与重复ID；编辑字段后，旧预览会失效。

下载配置后，将文件放在仓库根目录，命名为config.local.json，然后停止并重新npm start。工作台服务保持只读，不会自动启动项目或写入配置文件。打开原页不等于证明服务健康或允许iframe嵌入。

## 分类与置顶

每个项目的“分类”可设置分组、最多8个标签和置顶。首页和Ctrl+K搜索都会匹配标签。分类优先取当前浏览器个人设置，再取项目配置默认值；个人分类包含在工作台备份中，不修改项目本身。

## 命名布局

“布局模板”选择项目、排列和名称，保存当前阅读字号。最多12个模板，支持打开、重命名和删除。模板记录入口ID，不保存子项目内容。配置移除项目后，含旧ID的备份会被拒绝，不会静默删掉记录。

## 风格预览

支持沿用配置主题、宋韵米纸、清爽墨蓝；舒适/紧凑密度和16–22px阅读字号。可覆盖浅色模式的背景、正文、次要文字与强调色。主题为独立CSS，配置中的自定义主题仍可保留。

预览不会保存，取消、Escape或关闭会还原。确认后写入当前浏览器个人记录。系统核对目标主题的最终浅色配色，不使用当前深色画面替代检查；正文、次要文字、强调色和按钮前景对比度不足4.5:1时不允许应用。参与核验的主题颜色令牌须使用可解析的3/6位十六进制值。深色模式沿用主题自己的颜色。这不是完整无障碍认证。

## Agent交接包

在“给Agent的说明”中填写风格与布局偏好，生成JSON预览并下载。默认用槽位替代项目真实名称和URL，不包含便笺、源码路径或凭据。**手工输入的偏好会原样导出，请不要在其中写私人地址或秘密。**

这是供你交给自己Agent的说明，不会自动发送消息、调用模型或执行命令。恢复记录或重新打开说明窗口会让旧交接包失效；下载前还会核对当前设置是否与预览一致。

## 旧版兼容

v0.1的配置和个人备份可以读取，便笺、最近位置和现有布局保留，新增定制项初始化为默认。v0.2备份包含模板、分类和风格；恢复先预览，再确认。如果恢复v0.1备份，新增定制项会还原默认，预览会说明这一点。

不要将较旧的v0.1页面和v0.2页面同时用于同一浏览器Origin：旧版写回时可能丢弃它不认识的新字段。升级前导出备份；开发预览使用单独端口。
