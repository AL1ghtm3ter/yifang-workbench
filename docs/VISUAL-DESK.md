# 可视化案头

首页案头下面有三个视图：项目地图、任务接续、布局预览。

- **项目地图**：显示实际注册的项目，直接进入或展开连接说明。说明分别展示地址登记、浏览器载入事件与项目协议响应。收到ready仅表示项目回应了工作台协议；不能据此判断登录、业务健康或服务内容的新鲜程度。本次会话证据刷新页面后清空。原页链接始终保留。
- **任务接续**：点“记下下一步”，写标题、下一步与关联项目。手动选择正在做、稍后再做、我已完成，点击“继续这件事”打开关联项目。最多12件任务；状态仅代表你的个人记录，不更新子项目事实。移除后可以撤销最近一次移除。
- **布局预览**：以缩略图查看一页、左右、上下和已保存的模板。点击打开实际项目；模板继续通过“布局模板”管理。
- **阅读比例**：两个项目左右并排时，拖动中间分隔线；聚焦分隔线后，左右箭头按5%调整，Home/End跳到25%/75%，平分按钮恢复50%。比例会保存到当前记录；保存布局模板时一并保存。窄屏显示单栏，四项目或上下排列不显示分隔线。

任务和比例存储在当前浏览器/当前配置命名空间，并纳入个人备份。恢复先显示任务数量和比例，再明确确认替换。旧备份没有任务时会清空任务面板并恢复50%比例。任务文本不会发送给子页面，也不会进入默认Agent交接包或公开构建。

减少动态偏好下，连接说明直接显隐。项目内部页面样式和内容仍由项目负责。
